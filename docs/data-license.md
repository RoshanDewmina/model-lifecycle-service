# Dataset provenance and license

This project uses the 178-row **Wine** classification dataset distributed with scikit-learn. Scikit-learn documents its copy as originating from the UCI Machine Learning Repository. UCI identifies the dataset as chemical analyses of wines from three cultivars, cites Aeberhard and Forina (1992), DOI `10.24432/C5PC7J`, and publishes it under **Creative Commons Attribution 4.0 International (CC BY 4.0)**.

- UCI record and license: <https://archive.ics.uci.edu/dataset/109/wine>
- scikit-learn loader documentation: <https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_wine.html>
- CC BY 4.0 terms: <https://creativecommons.org/licenses/by/4.0/>

Attribution: Aeberhard, S. & Forina, M. (1992). *Wine* [Dataset]. UCI Machine Learning Repository. <https://doi.org/10.24432/C5PC7J>.

The repository's MIT license applies to original code and fixtures, not to the upstream dataset. No private or personal data is used.
